The common diagnostic harness adds the shared BenchTiming recorder to the owned four-engine driver JAR and optional boundary calls to Lightbench. Source is retained under matched/reproduction. The instrument helper operates on separate pulsar-profile and lightbench-profile checkouts and external starlight-src files from the pinned upstream. It adds independently written timing calls around setup, section handling, propagation, publication and cleanup. No reference-engine Java is distributed here. A final external build applies ordinary javac to the port's pure engine classes against its original JAR/fastutil/recorder, preserving every other original entry. Read the source helper and protocol before porting this local harness.

The recorder samples a deterministic hash of phase/index with mask15; warmup uses warmup-prefixed phases and executes the same recording path, then clears fully drained rows. The validator requires the exact positive warmup count and exact correspondence to native edit timings. Recording is disabled in the primary implementation-candidate latency experiment. The shared recorder rejects overlapping engine/task writers; it is intended for these isolated single-location fixtures, not unrestricted simultaneous worlds.

To recheck data, extract each study's raw-data.zip into its own study root, put its corresponding Python tools in tools/, create progress.json with status measurements-complete, and run its analyze.py. Use separate roots: the analyzers require48,32 or40 formal trials respectively and must not pool epochs. Plotting uses matplotlib3.11.2/numpy2.5.3; PLOT_PACKAGE_DIR can select a local package directory. Four-run primary summaries use median run means and run min–max, not confidence intervals. Late-index sensitivities remain in the matched/worker/candidate CSV/JSON.

For implementation candidates, package_variants.py replaces only enumerated class files in the frozen original Pulsar JAR. The unmodified rebuilt LightQueue and PulsarEngine classes matched the original bytes. The direction-mask helper is experimental and rejected; main3347942 includes only the late-partner scheduler and its tests. Prototype combined tests179 and main178 passed. Compiler/debug/JIT layout can influence observed effects; a controlled code effect is not the same as an instruction-level attribution.

The raw packages contain stage/status/result JSON and two-second per-PID process samples, plus manifests/protocols/checksums. They exclude Minecraft worlds, engine/mod JARs, account files and full logs. The original disposable-instance automation/templates and external GPL reference sources remain outside the repository. Methods permit rebuilding the procedure but do not guarantee byte-identical builds or identical timing on another computer.
